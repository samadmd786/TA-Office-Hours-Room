# Course materials (fictional)

Everything in this folder is made up for the demo. "CLD 101: Intro to Cloud
Computing" at "Northfield Institute" is not a real course or school, and every
name, date and policy here is invented. It is free to reuse under this repo's
MIT license.

| File | What it is |
|---|---|
| [syllabus.md](syllabus.md) | Course policies: grading, late policy, office-hours rules, academic integrity |
| [lectures/L01-cloud-basics.md](lectures/L01-cloud-basics.md) | Lecture 1: what the cloud is, IaaS/PaaS/SaaS |
| [lectures/L02-containers.md](lectures/L02-containers.md) | Lecture 2: containers and images |
| [lectures/L03-kubernetes-probes.md](lectures/L03-kubernetes-probes.md) | Lecture 3: Kubernetes liveness and readiness probes |
| [assignments/A3-health-checks.md](assignments/A3-health-checks.md) | Assignment 3 (graded): add health checks to a Deployment |
| [faq.md](faq.md) | Answers to common questions, kept up to date by the TA |

The agents cite these files as `file § slide N` (for example
`L03-kubernetes-probes.md § Slide 4`), so keep slide numbers stable when you
edit a lecture.
